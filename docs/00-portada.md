### Resumen

Koko App es una aplicación web comunitaria que centraliza en un solo lugar las
necesidades cotidianas de quienes conviven con animales en Orán: publicar y buscar
mascotas perdidas con mapa y avistamientos, ofrecer animales en adopción, consultar un
directorio verificado de veterinarias, identificar mascotas con una ficha digital
accesible por código QR, realizar denuncias por maltrato con seguimiento por código y
difundir casos urgentes que necesitan colaboración económica.

Está construida con React y Vite en el frontend y Supabase (PostgreSQL, autenticación y
almacenamiento) como backend, y se distribuye como aplicación web progresiva (PWA)
pensada para usarse desde el celular.
